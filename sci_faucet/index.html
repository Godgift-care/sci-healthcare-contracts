§SCI Healthcare — Test USDC Faucet (testnet only)

Lets anyone trying the testnet demo get a small amount of the demo settlement token, without a server holding the issuer key.

The token’s Stellar Asset Contract names this contract as its admin, so drip can mint. Each address may drip once per cooldown, the amount is fixed by the faucet admin, and an optional lifetime cap stops one address draining the faucet slowly forever. The admin can hand token administration back at any time with release_token_admin.

Never deploy this against a real asset. Admin rights over a real token here would let anyone mint it.
