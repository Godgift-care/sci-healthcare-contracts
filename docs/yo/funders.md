# Sísanwó ìtọ́jú fún ẹlòmíràn

Ẹ̀ ń sanwó fún ìtọ́jú kan pàtó ní ilé-ìwòsàn kan pàtó, fún ara yín tàbí fún ẹlòmíràn.

Tí ẹ bá ń sanwó fún ọ̀pọ̀lọpọ̀ voucher (ìwé-ẹ̀rí ìsanwó) láti inú wallet (àpò owó oní-nọ́ńbà) àjọ kan tí ọ̀pọ̀ ènìyàn jọ ń lò, tàbí láti inú àkáǹtì multisig,
ẹ ka [Sísanwó láti inú wallet àjọ](../guides/organisation-funders.md)
dípò èyí: ó ṣàlàyé ìfọwọ́sí, dídá owó padà sí àkáǹtì àjọ náà àti
ìtọ́jú àkọsílẹ̀.

## Ohun tí ẹ nílò

- Wallet Stellar kan. [Freighter](https://freighter.app) ni ọ̀pọ̀ ènìyàn máa ń yàn.
- Wallet yín tí a ṣètò sí **Testnet** nígbà tí a ṣì ń dán protocol náà wò.
- USDC díẹ̀ nínú wallet náà, àti trustline fún un (wo ìsàlẹ̀). Lórí testnet, ẹ gba USDC ìdánwò lọ́fẹ̀ẹ́ láti inú app: **My vouchers → Get test USDC** (ẹ̀ẹ̀kan lójúmọ́ fún wallet kọ̀ọ̀kan).
- Nọ́ńbà ìdánimọ̀ aláìsàn ní ilé-ìwòsàn àti kọ́kọ́rọ́ àṣírí tí ẹ̀yin méjèèjì fohùn ṣọ̀kan lé lórí.

## Nípa trustline

Stellar ń béèrè pé kí ẹ gbà ní gbangba láti di ohun-ìní kan mú kí ẹ tó lè gbà á. Èyí ni a ń pè ní trustline (ìlà ìgbẹ́kẹ̀lé), àti pé láìsí ọ̀kan fún USDC, wallet yín kò lè di í mú, ìsanwó náà yóò sì kùnà.

Lórí testnet, ẹ fi kún un fúnra yín nínú wallet yín. Nínú Freighter: **Manage assets → Add an asset**, kóòdù `USDC`, olùfúnni (issuer) `GCKX5KAFVF7GLFZ3JWQGJ4F62RYYZU67PI3TACBGKVPJ73JELMI3L4KR`.

## Sísanwó

1. **Ẹ so wallet yín pọ̀.** Ní apá òkè lọ́wọ́ ọ̀tún. A kò tọ́jú nǹkan kan pamọ́; ẹ lè yọ ọ́ kúrò nígbàkigbà.
2. **Ẹ yan ilé-ìwòsàn.** Àkójọ náà ń fi àwọn ilé-ìwòsàn tí a ti fìdí wọn múlẹ̀ nìkan hàn, pẹ̀lú iye owó tí wọ́n kọ sílẹ̀.
3. **Ẹ yan iṣẹ́ ìtọ́jú.** Ilé-ìwòsàn ni ó ń fi iye owó lélẹ̀, a sì ń tẹ̀ ẹ́ jáde lórí blockchain.
4. **Ẹ tẹ nọ́ńbà ìdánimọ̀ aláìsàn àti kọ́kọ́rọ́ àṣírí sílẹ̀.**

   Nọ́ńbà ìdánimọ̀ náà ni ohunkóhun tí ó ń dá aláìsàn mọ̀ ní ilé-ìwòsàn náà — nọ́ńbà káàdì, nọ́ńbà ìforúkọsílẹ̀. Kọ́kọ́rọ́ náà jẹ́ àṣírí tí ẹ jọ ní, tí ó kéré tán ní ohun kikọ 32.

   A ń da àwọn méjèèjì pọ̀ *nínú aṣàwákiri (browser) yín* sí iye kan tí kò ṣeé kà. Kò sí ọ̀kan nínú wọn tí ó ń kúrò lórí ẹ̀rọ yín. Kò sí ọ̀kan tí a ń fi ránṣẹ́ sí wa. Kò sí ọ̀kan tí ó ń lọ sórí blockchain.

   **Ẹ máa lo nọ́ńbà ìdánimọ̀ àti kọ́kọ́rọ́ kan náà nígbà gbogbo fún ẹni kan náà.** Àwọn ni ó ń so ìtàn ìtọ́jú rẹ̀ pọ̀. Tí kọ́kọ́rọ́ náà bá sọnù, a kò ní lè wá àwọn ìwé-ẹ̀rí ìsanwó àtẹ̀yìnwá mọ́. Kò sí ọ̀nà láti gbà á padà — ìyẹn ni iye tí a ń san fún pé àwa kò di í mú.

5. **Ẹ fìdí iye owó múlẹ̀.** Ẹ lè san ju iye owó tí a kọ sílẹ̀ lọ, ṣùgbọ́n kò gbọdọ̀ dín sí i láé.
6. **Ẹ buwọ́lù ú.** Wallet yín yóò fi ìdúnàádúrà (transaction) náà hàn. Tí ẹ bá fọwọ́ sí i, USDC náà yóò lọ sínú contract (àdéhùn oní-kóòdù).

Owó yín ti wà ní ìpamọ́ (escrow) báyìí. Kì í ṣe ti ilé-ìwòsàn síbẹ̀.

## Lẹ́yìn ìsanwó

Ẹ máa wò ó lábẹ́ **My vouchers**.

| Ipò | Ohun tí ó túmọ̀ sí |
| --- | --- |
| Funded | Ó wà ní ìpamọ́. Aláìsàn kò tíì wá. |
| Claimed | Ilé-ìwòsàn sọ pé aláìsàn ti dé. |
| Attested | Attester (ẹlẹ́rìí) kan ti fìdí rẹ̀ múlẹ̀ pé a ṣe ìtọ́jú náà. Àsìkò àtakò ti ṣí sílẹ̀. |
| Settled | A ti san owó fún ilé-ìwòsàn. |
| Refunded | Owó náà ti padà sọ́dọ̀ yín. |

## Tí nǹkan kan bá lọ ní ọ̀nà òdì

**Ẹ san ju iye owó lọ ní àṣìṣe.** Nígbà tí voucher náà ṣì wà ní `Funded`, ẹ lè gba àfikún náà padà láì fi voucher náà sílẹ̀: `reduce_amount` ń mú iye owó tí ó wà ní ìpamọ́ wálẹ̀ sí iye owó tí ilé-ìwòsàn kọ sílẹ̀, ó sì ń dá ìyàtọ̀ náà padà fún yín. Kò ní lọ sísàlẹ̀ iye owó tí a kọ sílẹ̀ láé, a sì ti pa á mọ́ ní kété tí ilé-ìwòsàn bá ti béèrè fún voucher náà. Web app kò tíì ní bọ́tìnnì yìí — wallet kan tàbí olùṣàfikún (integrator) lè pe contract náà tààrà.

**Aláìsàn kò lọ rárá.** Ẹ dúró di ọjọ́ ìparí, lẹ́yìn náà ẹ tẹ **Refund me**. Ẹ ó gba gbogbo owó náà padà, láìsí owó ìṣẹ́. Ẹnikẹ́ni lè ṣe èyí, nítorí náà ẹ kò gbára lé wa. Tí a bá dá ilé-ìwòsàn dúró kí ó tó béèrè fún voucher náà, ẹ lè gba owó padà lẹ́sẹ̀kẹsẹ̀ dípò dídúró de ọjọ́ ìparí.

**Ilé-ìwòsàn béèrè fún un, ṣùgbọ́n kò sí ẹni tí ó fìdí ìbẹ̀wò náà múlẹ̀.** Ẹ lè ṣe àtakò lẹ́sẹ̀kẹsẹ̀. Tí ẹ kò bá ṣe nǹkan kan, voucher náà yóò di èyí tí a lè dá owó rẹ̀ padà ní ọjọ́ méje lẹ́yìn ọjọ́ ìparí rẹ̀, **Refund me** yóò sì tún farahàn.

**Ilé-ìwòsàn béèrè fún un ṣùgbọ́n kò tọ́jú wọn.** Ẹ tẹ **Dispute** nígbà tí ipò náà jẹ́ `Claimed` tàbí `Attested`. Owó náà yóò dúró sójú kan, alábòójútó (administrator) kan yóò sì ṣàyẹ̀wò rẹ̀. Ẹ ṣe èyí kí àsìkò àtakò tó parí — wákàtí 72 lẹ́yìn ìjẹ́rìí. Ní kété tí ó bá ti parí, ìsanwó ìkẹyìn (settlement) yóò ṣẹlẹ̀ fúnra rẹ̀, kò sì ṣeé yí padà.

**Àsìkò náà ti parí, ó sì kọjá yín.** Owó náà ti lọ sọ́dọ̀ ilé-ìwòsàn. Protocol kò lè gbà á padà. Ẹ bá ilé-ìwòsàn náà sọ̀rọ̀ tààrà.

## Ohun tí èyí kò ṣe

Kò fi dá yín lójú pé ìtọ́jú náà *dára*. Ó fi dá yín lójú pé ẹgbẹ́ olómìnira kan jẹ́rìí pé ó ṣẹlẹ̀, àti pé ẹ ní àsìkò láti tako.
