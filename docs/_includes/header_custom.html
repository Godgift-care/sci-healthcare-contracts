{%- comment -%} Version banner for the versioned docs site. scripts/build-docs-site.sh sets docs_version ("main" or a release tag), docs_latest (the newest release tag) and docs_root (the site root) for every build, and copies this file into each release snapshot. Without those values (GitHub's legacy Pages build, or `jekyll serve` on docs/) nothing is rendered. just-the-docs offers this include in its header bar, which it hides on small screens. The banner is rendered here, so it shows on a desktop without JavaScript, and the script below moves it to the top of the page content, where it shows at every width.
