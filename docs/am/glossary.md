# የቴክኒክ ቃላት መዝገበ ቃላት

የአማርኛ መመሪያዎች የሚከተሉት አጭር መዝገበ ቃላት። አንዳንድ ቃላት በመተግበሪያው፣ በዋሌቱ እና በውሉ ውስጥ እንደዚያው ስለሚታዩ በእንግሊዝኛ ይቀራሉ፤ የተቀሩት በሁሉም ቦታ በተመሳሳይ መንገድ ይተረጎማሉ። ሙሉ ትርጉሞቹ በ[እንግሊዝኛው መዝገበ ቃላት](../glossary.md) ውስጥ ይገኛሉ።

| English | አማርኛ | ማስታወሻ |
| --- | --- | --- |
| voucher | ቫውቸር | ለተወሰነ ክሊኒክ ለተወሰነ አገልግሎት አስቀድሞ የተከፈለ ገንዘብ። |
| funder | ከፋይ | የቫውቸሩን ገንዘብ የሚከፍል። |
| clinic / provider | ክሊኒክ / አገልግሎት ሰጪ | ክፍያ የሚቀበል ክሊኒክ፣ ፋርማሲ ወይም ላቦራቶሪ። |
| patient | ታካሚ | ሕክምናውን የሚቀበል። |
| attester | አረጋጋጭ | ሕክምና መሰጠቱን ለማረጋገጥ የተፈቀደለት ሰው። |
| attest | ማረጋገጥ | የቅሬታ ጊዜውን የሚከፍተው የ `attest` ጥሪ። |
| administrator (admin) | አስተዳዳሪ | ክሊኒኮችን የሚያረጋግጥ እና አረጋጋጮችን የሚሾም። |
| escrow | አደራ | ውሉ እስከ ክፍያ ወይም ተመላሽ ድረስ የሚይዘው ገንዘብ። |
| dispute | ቅሬታ | አስተዳዳሪ እስኪወስን ገንዘቡን የሚያግድ ተቃውሞ። |
| dispute window | የቅሬታ ጊዜ | ከማረጋገጫው በኋላ 72 ሰዓት። |
| settlement / settle | ክፍያ (ለክሊኒኩ) | ከቅሬታ ጊዜው በኋላ ገንዘቡን ወደ ክሊኒኩ ማስተላለፍ። |
| refund | ተመላሽ | ገንዘቡ ወደ ከፋዩ መመለሱ። |
| expiry | የማብቂያ ቀን | ቫውቸሩ ከዚያ በኋላ ሊጠየቅ የማይችልበት ቀን። |
| protocol fee | የፕሮቶኮል ክፍያ | ከቫውቸሩ መጠን 1%። |
| wallet | ዋሌት | የ Stellar አካውንትዎን ቁልፎች የሚይዝ መተግበሪያ። |
| trustline | trustline | አልተተረጎመም፦ Stellar እና ዋሌቶች የሚጠቀሙበት ስም። |
| smart contract | ውል | በ blockchain ላይ የሚሰራ ፕሮግራም። |
| blockchain | blockchain | አልተተረጎመም። |
| secret key | ሚስጥራዊ ቁልፍ | በከፋዩ እና በታካሚው መካከል ያለ የጋራ ሚስጥር። |
| receipt | ደረሰኝ | በክፍያ ጊዜ የሚፈጠር መዝገብ። |

የሁኔታ ስሞች (`Funded`፣ `Claimed`፣ `Attested`፣ `Settled`፣ `Refunded`፣ `Pending`፣ `Active`) እና የመተግበሪያው አዝራሮች (**My vouchers**፣ **Refund me**፣ **Dispute** ወዘተ) መተግበሪያው ከሚያሳየው ጋር እንዲመሳሰሉ በእንግሊዝኛ ይቀራሉ።
