# مسرد المصطلحات التقنية

مسرد قصير تلتزم به الأدلة العربية. بعض المصطلحات تبقى بالإنجليزية لأنها تظهر هكذا في التطبيق والمحفظة والعقد؛ أما البقية فتُترجم بالطريقة نفسها في كل مكان. التعريفات الكاملة في [المسرد الإنجليزي](../glossary.md).

| English | العربية | ملاحظة |
| --- | --- | --- |
| voucher | قسيمة | مبلغ مدفوع مسبقًا لخدمة محددة في عيادة محددة. |
| funder | المموّل | من يدفع قيمة القسيمة. |
| clinic / provider | العيادة / مقدم الخدمة | عيادة أو صيدلية أو مختبر يتلقى الدفع. |
| patient | المريض | من يتلقى الرعاية. |
| attester | المُصادِق | شخص مخوّل بتأكيد تقديم الرعاية. |
| attest | المصادقة | استدعاء `attest` الذي يفتح نافذة الاعتراض. |
| administrator (admin) | المسؤول | يتحقق من العيادات ويعيّن المُصادِقين. |
| escrow | الضمان | أموال يحتفظ بها العقد حتى التسوية أو الاسترداد. |
| dispute | اعتراض | يجمّد الأموال حتى يقرر المسؤول. |
| dispute window | نافذة الاعتراض | 72 ساعة بعد المصادقة. |
| settlement / settle | التسوية | تحويل الأموال إلى العيادة بعد نافذة الاعتراض. |
| refund | استرداد | عودة الأموال إلى المموّل. |
| expiry | تاريخ الانتهاء | التاريخ الذي لا يمكن بعده المطالبة بالقسيمة. |
| protocol fee | رسوم البروتوكول | 1% من مبلغ القسيمة. |
| wallet | محفظة | تطبيق يحمل مفاتيح حسابك على Stellar. |
| trustline | خط الثقة (trustline) | يُذكر الاسم الإنجليزي لأنه ما تعرضه المحافظ. |
| smart contract | العقد | برنامج يعمل على البلوكشين. |
| on chain | على السلسلة | مسجل على البلوكشين. |
| secret key | المفتاح السري | سرّ مشترك بين المموّل والمريض. |
| receipt | إيصال | سجل يُنشأ عند التسوية. |

تبقى أسماء الحالات (`Funded` و`Claimed` و`Attested` و`Settled` و`Refunded` و`Pending` و`Active`) وأزرار التطبيق (**My vouchers** و**Refund me** و**Dispute** وغيرها) بالإنجليزية لتطابق ما يعرضه التطبيق.
