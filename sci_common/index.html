§SCI Healthcare — shared contract helpers

Storage policy and admin handover used by registry, voucher and receipt. These are the parts that were copied into every contract and then drifted: TTL numbers, how an entry is extended, and the two-step handover that protects an admin or minter role from a typo.

Nothing here defines a public contract interface. Each contract keeps its own DataKey, error type and events; only the storage mechanics are shared, so the on-chain interface is unchanged by using this crate.

What breaks if this is wrong: an entry extended with a shorter TTL than the contract documents is archived early, and a handover that skips the acceptance step strands a role on an address nobody controls.
